## 🗺️ ROADMAP DE IMPLEMENTAÇÃO

### 🔧 FASE A — Correções Críticas (Prioridade ALTA)

> Bugs que impactam a experiência do usuário diretamente.

| # | Correção | Complexidade | Arquivos Envolvidos |
|---|----------|-------------|---------------------|
| A1 | TTS: "dois estrelas" → "duas estrelas" | Baixa | TaskCompletionScreen.kt, TtsManager.kt |
| A2 | Rotação: TTS repete frase | Média | TaskExecutionViewModel.kt, TaskExecutionScreen.kt |
| A3 | Rotação: imagem não exibe em landscape | Média | TaskExecutionScreen.kt |
| A4 | Avanço múltiplo: confirmar antes de avançar | Média | TaskExecutionViewModel.kt, TaskExecutionScreen.kt |

**Estimativa:** 1-2 sessões de trabalho

#### Detalhamento:

**A1 — Concordância de gênero no TTS**
- Problema: "Você ganhou 2 estrelas" lido como "dois estrelas"
- Solução: Criar função auxiliar que gera texto com número por extenso feminino ("duas", "três", etc.)
- Arquivo principal: onde monta a string de estrelas ganhas

**A2 — TTS repete ao rotacionar**
- Problema: `onConfigurationChange` recria a tela e dispara TTS novamente
- Solução: Flag no ViewModel que marca se TTS já foi executado para o passo atual
- Alternativa: Usar `rememberSaveable` para estado de TTS

**A3 — Imagem some em landscape**
- Problema: Layout não se adapta à rotação
- Solução: Detectar orientação e ajustar layout (ScrollableColumn com imagem redimensionada)

**A4 — Avanço imediato de vários passos**
- Problema: Usuário pode tocar rapidamente e pular passos
- Solução: Debounce no botão de avanço + confirmação via TTS ("Você realmente terminou?")
